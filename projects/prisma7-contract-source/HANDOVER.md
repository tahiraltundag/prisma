## What the project is

Prisma 7 users keep their `schema.prisma` while Prisma 7 still owns migrations. Instead of `contract infer` plus hand edits (the public guide's current phase 2), Prisma 8 reads the Prisma 7 file directly as a contract source:

```ts
contract: prisma7Schema('prisma/schema.prisma')
```

`contract emit`, `db sign`, and `db verify` then work unchanged with zero findings against the database Prisma 7 built. Every construct Prisma 8 cannot express is a hard error naming the field, line, and edit. No warnings, nothing silent. See `spec.md` for the settled design and `design-notes.md` for the alternatives that were rejected and why.

## Practical snags in this repo

- A shell hook rejects any Bash command whose text contains the word "npm", including inside strings such as the alias `npm:prisma@7.10.0`. Use the file tools for content with that word.
- Root `pnpm typecheck` can fail on `integration-tests` with "cannot find module `@prisma/orm-postgres/...`" while that package rebuilds; rerun `pnpm --filter integration-tests typecheck` alone. Not a defect in the branch.
- `pnpm fixtures:check` needs install, build, install again before its result means anything.
- `pnpm-workspace.yaml` has a pinned `trustPolicyExclude` for `prisma@7.10.0` (no provenance); the example's Prisma 7 packages need network once for engine download.
- Save long test output to a file under `wip/` and read it; the repo rule forbids rerunning to grep.

## Learnings ledger (copied from the gitignored `learnings.md`)

- **Root typecheck races with a package rebuild.** `integration-tests` does not declare `@prisma/orm-postgres` as a dependency, so turbo can typecheck it while that package's `dist` is being replaced. Rerun the one task.
- **Ground truth from Prisma 7 is cheap.** `pnpm dlx prisma@7.10.0 migrate diff --from-empty --to-schema <schema> --script` from a scratch directory under `wip/` produces the exact SQL Prisma 7 creates, no lockfile change. It settled several rules and corrected the spec three times in one dispatch.
- **A fact that agrees with the spec can still break a downstream requirement.** The contract accepts generators on nullable columns, as assumed, but the round-trip requirement (the converter must print every accepted contract) turned that into a decision. Check verification items against every cross-cutting requirement.
- **Real foreign SQL is a verify test suite.** Applying Prisma 7's actual DDL found four Prisma 8 verify defects no fixture had reached.
- **A README-only QA runner finds what reviewers and gates cannot.** Nine dispatches passed review green; a runner following only the README hit two blockers in ten minutes.
- **Specify user-facing slices from the public docs, not project notes.** See Will's rules above.
